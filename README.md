# CYCU-CAL Study Group Slides

Slides for the CYCU-CAL Study Group, built with [Slidev](https://sli.dev).

The study group's practice problems run on the group judge, [cal-study-group-judge](https://github.com/Nat1anWasTaken/cal-study-group-judge).

## Development

```sh
pnpm install
pnpm dev week-7.md           # preview a deck locally
pnpm build                   # build every week-*.md deck into dist/
```
