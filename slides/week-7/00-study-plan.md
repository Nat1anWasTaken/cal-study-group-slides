# 讀書會的規劃

- **前 2～3 週**：補齊老師上過的部分，讓大家站在同一個起跑點
- **概念建立後**：加入我認為重要、能幫助理解更多的東西
- **後期**：把 C 的概念擴張到 Python 等其他語言
